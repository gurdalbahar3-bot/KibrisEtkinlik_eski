## DÜZELTME 6 — EKSİK TABLO SPESİFİKASYONLARI

### `bus_routes`

| Kolon | Tip | Kısıt |
|-------|-----|-------|
| id | uuid | PK DEFAULT gen_random_uuid() |
| event_id | uuid | NOT NULL, FK → events(id) ON DELETE CASCADE |
| name | text | NOT NULL |
| description | text | |
| is_active | boolean | NOT NULL DEFAULT true |
| created_at | timestamptz | NOT NULL DEFAULT now() |
| updated_at | timestamptz | NOT NULL DEFAULT now() |

**INDEX:** (event_id)  
**RLS:** SELECT public (published event); INSERT/UPDATE/DELETE event owner + staff(event)

---

### `bus_stops`

| Kolon | Tip | Kısıt |
|-------|-----|-------|
| id | uuid | PK |
| route_id | uuid | NOT NULL, FK → bus_routes(id) ON DELETE CASCADE |
| stop_name | text | NOT NULL |
| departure_time | time | NOT NULL |
| latitude | numeric | |
| longitude | numeric | |
| sort_order | int | DEFAULT 0 |
| created_at | timestamptz | NOT NULL DEFAULT now() |

**INDEX:** (route_id)  
**UNIQUE:** (route_id, stop_name, departure_time)  
**RLS:** bus_routes ile aynı (event owner üzerinden)
